CONDITION UI コンディション可視化アプリのUI

働く人のコンディションを、天気のように伝える

01 — 天気で状態を表すTOP画面：その日の状態を天気（晴れ・くもり・雨）で表し、背景色と人型のモチーフが変わるTOP画面のデザインカンプ3案で、製品名・機能名は伏せています。

タグUI・UXデザイン調査CX・体験設計ビジュアルヘルスケア

従業員のコンディションを可視化するサービスの新機能に向けて、調査の焦点の設定、習慣化の機能の検討、機能マップとコンセプトの整理から、画面デザインの納品までを進めた。コンディションを天気やバブルで表す画面と、案内役のキャラクターを含む。
